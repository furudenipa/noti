The Git tag [3.9.0](https://codeberg.org/roble/noti/releases/tag/3.9.0) points
to the last fully `MIT` licensed commit. Commits from 3.9.0 and prior will
remain fully MIT licensed. Future modifications to files with multiple authors
will retain their original `MIT` license.

code under `cmd/` which will be licensed as `AGPL-3.0-or-later`.

See [REUSE.toml](REUSE.toml) and source code file headers for exact license
information.

## No AI/LLM policy

Any contributions generated by AIs or LLMs are not permitted. This includes,
but is not limited to, bug reports, comments, documentation, source code,
artwork, etc.
